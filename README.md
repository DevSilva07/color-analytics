# Color Analytics — Demo educacional

Este projeto é uma alternativa segura ao pedido de um "motor de previsão" para resultados de Bac Bo.

Ele demonstra:
- frontend responsivo em HTML/CSS/JavaScript;
- backend Python + Flask;
- API REST;
- registro de resultados;
- estatísticas de frequência;
- barras de visualização;
- histórico;
- interface para telemóvel.

## Executar

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

```bash
pip install -r requirements.txt
python app.py
```

Abra:
http://localhost:5000

## Evolução possível

Para um projeto legítimo de análise de dados, pode-se adicionar:
- upload de CSV;
- pandas;
- gráficos históricos;
- métricas de qualidade;
- comparação de modelos em dados históricos;
- dashboard de análise;
- exportação de relatórios.

O sistema não afirma prever o próximo resultado de um jogo de azar.
